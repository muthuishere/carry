# carry 1-Click (DigitalOcean Kubernetes)
Copy this folder to `stacks/carry/` in a fork of https://github.com/digitalocean/marketplace-kubernetes,
open a PR, then submit the listing in the DO Vendor Portal (https://cloud.digitalocean.com/vendorportal).
Getting started text: see ../../listing/listing.md. Requires a published Helm repo (deploy.sh assumes
https://muthuishere.github.io/carry - adjust if the chart is served from OCI).
